create its file here and record decisions, gotchas, and how-tos. Expected files as the project
grows (create when needed, don't pre-create):

- `flutter-app.md` — app structure, state management, theming
- `database.md` — Postgres schema decisions, indexes
- `migration.md` — DB migration workflow
- `deployment.md` — how/where the server is deployed
- `tachibk-format.md` — parsing notes beyond what's in docs/phase-1
- `cover-fetching.md` — per-source quirks discovered in practice
